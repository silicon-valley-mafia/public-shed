## Intended use

- Store files and supporting materials in folders organized by topic or project.
- Use GitHub Issues to track tasks, questions, troubleshooting, and follow-ups; attach relevant files where useful.
- Keep useful references and working notes alongside related materials.
- Use folders as needed rather than enforcing a rigid taxonomy.

## Suggested practices

- Give files and folders descriptive names.
- Add a short README in folders when their purpose is not obvious.
- Keep credentials, private keys, personal identifiers, financial records, and other sensitive information out of this public repository.
- Prefer links or redacted examples when an issue needs to refer to private material.
